- Turbo 8.0.23: https://github.com/hotwired/turbo/blob/v8.0.23/MIT-LICENSE
- Stimulus 3.2.2: distributed `@hotwired/stimulus/LICENSE.md`.

The build emits these notices alongside the bundled assets. Turbo's npm package
includes its copyright header and MIT package metadata but omits the full license
file; the tagged source notice is preserved here.
